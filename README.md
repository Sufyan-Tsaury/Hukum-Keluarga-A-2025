# Portal 3D HK A 2025 | UIN Siber Syekh Nurjati Cirebon

Website interaktif 3D **Chapter of Us — Hukum Keluarga Kelas A Angkatan 2025 (UINSSC Cirebon)** dengan karakter **Dewi Themis Modern** dan lima objek simbol keadilan interaktif.

## Lokasi Project
`C:\Users\sufya\.gemini\antigravity\scratch\hk-a-2025-3d`

## Cara Melanjutkan
1. Buka aplikasi **Antigravity**, klik **Open Folder / Set Workspace**, lalu pilih folder:
   `C:\Users\sufya\.gemini\antigravity\scratch\hk-a-2025-3d`
2. Untuk menyalakan server lokal:
   - Klik dua kali file `jalankan-dev.bat`, **atau**
   - Jalankan di terminal: `npm.cmd run dev`
